# دوره‌ی Laravel از 0 تا 1000 | Rayvo — نسخه‌ی Netlify

## ساختار
- `public/` : صفحه‌ی فروش، صفحه‌ی ورود، فایل‌های ظاهری و پنل مدیریت (`public/rv-admin-k7q2x9/`)
- `content/` : درس‌ها و zip پروژه‌ها (**بیرون از پوشه‌ی منتشرشده**؛ فقط از طریق تابع و با جلسه‌ی معتبر ارسال می‌شود)
- `netlify/functions/` : ورود، بررسی جلسه، دروازه‌ی محتوا، API پنل
- `netlify.toml`، `package.json` : تنظیمات (دست نزنید)

## راه‌اندازی
1. ریپوی **Private** در گیت‌هاب بسازید و **محتوای همین پوشه** را آپلود کنید (خود پوشه‌ی بیرونی نه، محتوایش).
2. در Netlify: Add new project ← Import from Git ← همان ریپو. چیزی را تغییر ندهید و Deploy کنید.
3. Site configuration ← Environment variables، چهار متغیر داخل فایل `متغیرهای-Netlify.txt` را بسازید. بعد Deploys ← Trigger deploy ← Deploy site.
4. آدرس `https://اسم-سایت-شما.netlify.app/rv-admin-k7q2x9/` را باز کنید، وارد شوید و «وضعیت سیستم» را بزنید. همه‌چیز باید ✅ باشد.
5. بهتر است پوشه‌ی `public/rv-admin-k7q2x9` را در گیت‌هاب به یک نام تصادفی دیگر تغییر دهید (اولش `rv-admin-` بماند).

## کار روزانه (همه از پنل، بدون کد و بدون deploy)
- **ساخت کد:** نام و شماره ← «ساخت کد دسترسی» ← پیام آماده کپی می‌شود ← در تلگرام برای خریدار بفرستید.
- **غیرفعال/فعال:** دسترسی همان لحظه قطع/وصل می‌شود، حتی برای کسی که الان داخل است.
- **ریست:** وقتی خریدار مرورگر یا گوشی عوض کرد.
- **کد جدید:** اگر کد لو رفت. کد قبلی و جلسه‌اش باطل می‌شود.
- **حذف:** کد و دسترسی برای همیشه پاک می‌شود.

## درس‌های رایگان
فهرست، مقدمه، راه‌اندازی محیط کار و مبانی PHP ۱. برای تغییر، آرایه‌ی `FREE` را هم در `netlify/lib/auth.mjs` (تعیین‌کننده) و هم در `public/assets/js/rayvo.js` (فقط برای نمایش قفل) یکسان ویرایش کنید.

## محدودیت‌ها (صادقانه)
- «یک‌بار مصرف» یعنی قفل شدن به اولین مرورگر. اگر خریدار کوکی را پاک کند یا گوشی عوض کند، باید ریستش کنید.
- اسکرین‌شات یا کپی دستی را هیچ سیستمی صددرصد نمی‌بندد. واترمارک نام خریدار روی هر صفحه و امکان باطل کردن کد، بازدارنده‌ی اصلی است.
- پلن رایگان Netlify سقف دارد؛ قبل از فروش زیاد، شرایط فعلی را در سایت Netlify ببینید.
