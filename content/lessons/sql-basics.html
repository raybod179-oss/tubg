مبانی SQL و MySQL با phpMyAdmin

دیتابیس جای نگهداری داده‌های سایت است. با phpMyAdmin یک دیتابیس می‌سازی و پنج دستور اصلی SQL را اجرا می‌کنی.

۱. ورود به phpMyAdmin

XAMPP: Apache و MySQL را Start کن و برو به http://127.0.0.1/phpmyadmin/. اگر Laragon داری: Start All، بعد Database ← Open یا همان آدرس. کاربر پیش‌فرض root و گذرواژه خالی است (فقط روی سیستم شخصی).

۲. ساخت دیتابیس و جدول

از تب SQL این را اجرا کن:

کدساخت جدول
CREATE DATABASE shop_lab CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE shop_lab;

CREATE TABLE products (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(120) NOT NULL,
  price INT NOT NULL,
  stock INT NOT NULL DEFAULT 0
);

۳. چهار عمل CRUD

ساخت، خواندن، ویرایش، حذف:

کدCRUD
INSERT INTO products (name, price, stock) VALUES ('هدفون', 450000, 10);
SELECT * FROM products WHERE price > 100000 ORDER BY price DESC;
UPDATE products SET stock = 9 WHERE id = 1;
DELETE FROM products WHERE id = 1;

۴. تمرین

جدول categories بساز و ۳ ردیف وارد کن. بعد فقط ردیفی را که اسمش با «ل» شروع می‌شود با LIKE 'ل%' بخوان.

اشتباه‌های رایج

  1. نوشتن UPDATE یا DELETE بدون WHERE (کل جدول تغییر می‌کند).
  2. فراموش‌کردن utf8mb4 و خراب‌شدن حروف فارسی.
  3. روشن‌نبودن MySQL در XAMPP.
