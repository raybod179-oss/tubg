بلادرنگ (Broadcasting)

وقتی چیزی در سرور اتفاق می‌افتد (سفارش جدید)، بدون رفرش صفحه به مرورگر برسد.

۱. نصب

لاراول ۱۲ و ۱۳ دستور آماده دارد و Reverb سرور WebSocket رسمی لاراول است.

کدartisan
php artisan install:broadcasting
php artisan reverb:start

۲. Event قابل پخش

کدEvent
class OrderPlaced implements ShouldBroadcast
{
    public function __construct(public Order $order) {}

    public function broadcastOn(): array
    {
        return [new Channel('orders')];
    }
}

OrderPlaced::dispatch($order);

۳. دریافت در مرورگر

کدEcho
Echo.channel('orders').listen('OrderPlaced', (e) => {
    console.log('سفارش جدید', e.order.id);
});

۴. کانال خصوصی

برای داده‌ی حساس از PrivateChannel و فایل routes/channels.php استفاده کن تا فقط کاربر مجاز گوش بدهد.

اشتباه‌های رایج

  1. پخش داده‌ی حساس روی کانال عمومی.
  2. روشن‌نبودن Worker صف (Eventهای ShouldBroadcast از صف می‌گذرند).
