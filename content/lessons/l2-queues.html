صف (Queue) و Job

کارهای کند (ارسال ایمیل، ساخت گزارش) را از درخواست کاربر جدا می‌کنیم تا سایت سریع بماند.

۱. تنظیم صف

در پروژه‌ی تازه، صف روی دیتابیس است و جدول jobs از قبل در migrationها هست.

کدenv
# .env
QUEUE_CONNECTION=database

php artisan migrate

۲. ساخت Job

کدJob
php artisan make:job SendOrderReport

// app/Jobs/SendOrderReport.php
class SendOrderReport implements ShouldQueue
{
    use Queueable;

    public function __construct(public int $orderId) {}

    public function handle(): void
    {
        // کار سنگین اینجا
    }
}

// ارسال به صف
SendOrderReport::dispatch($order->id);

۳. اجرای Worker

بدون Worker هیچ Job اجرا نمی‌شود. روی هاست باید با Supervisor همیشه روشن بماند.

کدartisan
php artisan queue:work
php artisan queue:failed        # Jobهای شکست‌خورده
php artisan queue:retry all

۴. تمرین

ارسال ایمیل تأیید سفارش را به یک Job منتقل کن و زمان پاسخ ثبت سفارش را مقایسه کن.

اشتباه‌های رایج

  1. نزدن queue:work و تعجب از اجرا‌نشدن Job.
  2. نوشتن کد Job بعد از تغییر و فراموش‌کردن ری‌استارت Worker (queue:restart).
