ساخت پکیج لاراول

کدی که در چند پروژه تکرار می‌شود را به پکیج تبدیل کن؛ همان‌طور که Spatie و دیگران می‌کنند.

۱. ساختار

کدساختار
my-package/
├── composer.json
└── src/
    ├── MyPackageServiceProvider.php
    └── Greeter.php

۲. composer.json

کدcomposer.json
{
  "name": "rayvo/my-package",
  "autoload": { "psr-4": { "Rayvo\\MyPackage\\": "src/" } },
  "extra": { "laravel": { "providers": ["Rayvo\\MyPackage\\MyPackageServiceProvider"] } }
}

۳. ServiceProvider

کدProvider
class MyPackageServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        $this->app->singleton(Greeter::class);
    }
}

۴. استفاده‌ی محلی

در composer.json پروژه‌ی اصلی:

کدlocal
"repositories": [{ "type": "path", "url": "../my-package" }]

composer require rayvo/my-package:@dev

اشتباه‌های رایج

  1. فراموش‌کردن extra.laravel.providers و ثبت‌نشدن خودکار Provider.
  2. اشتباه در namespace و مسیر psr-4؛ بعد از تغییر composer dump-autoload بزن.
