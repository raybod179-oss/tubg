Livewire: مقدمه

Livewire اجازه می‌دهد صفحه‌ی پویا (جستجوی زنده، فرم‌های تعاملی) را بیشتر با PHP و Blade بنویسی، بدون نوشتن API و جاوااسکریپت سنگین.

۱. نصب و کامپوننت اول

نسخه و نحوه‌ی لایه (layout) را با مستندات رسمی Livewire چک کن؛ ساختار زیر برای Livewire نسخه‌ی ۳ به بعد است.

کدartisan
composer require livewire/livewire
php artisan make:livewire Counter

۲. کلاس و ویو

کدCounter
// app/Livewire/Counter.php
class Counter extends Component
{
    public int $count = 0;
    public function increment(): void { $this->count++; }
    public function render() { return view('livewire.counter'); }
}

{{-- resources/views/livewire/counter.blade.php --}}
<div>
    <button wire:click="increment">+</button>
    <span>{{ $count }}</span>
</div>

{{-- استفاده در هر ویو --}}
<livewire:counter />

۳. جستجوی زنده

کدsearch
public string $q = '';

public function render()
{
    return view('livewire.search', [
        'products' => Product::where('name', 'like', "%{$this->q}%")->limit(10)->get(),
    ]);
}

<input wire:model.live.debounce.300ms="q">

اشتباه‌های رایج

  1. نگذاشتن یک عنصر ریشه‌ی واحد در ویو کامپوننت.
  2. اعتماد به داده‌ی public کامپوننت؛ کاربر می‌تواند آن را دستکاری کند، پس دوباره اعتبارسنجی و مجوزدهی کن.
