دیپلوی روی هاست و VPS

سایت لاراولی باید ریشه‌ی وب‌سرورش پوشه‌ی public باشد، نه ریشه‌ی پروژه.

۱. آماده‌سازی .env

کدenv
APP_ENV=production
APP_DEBUG=false
APP_URL=https://yoursite.ir
# اطلاعات دیتابیس واقعی

۲. فرمان‌های دیپلوی

کدdeploy
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan storage:link
php artisan config:cache
php artisan route:cache
php artisan view:cache

۳. هاست اشتراکی

اگر فقط به public_html دسترسی داری: محتوای public را آنجا بگذار و مسیر index.php را به پوشه‌ی پروژه (بیرون public_html) اصلاح کن. بقیه‌ی پروژه نباید از وب در دسترس باشد. پوشه‌های storage و bootstrap/cache باید قابل نوشتن باشند.

۴. VPS

Nginx + PHP-FPM + MySQL، گواهی HTTPS با Certbot، Supervisor برای queue:work و یک Cron برای schedule:run. روی سرور ابتدا فقط پورت‌های لازم را باز کن.

اشتباه‌های رایج

  1. بازگذاشتن APP_DEBUG=true روی سایت زنده.
  2. قراردادن ریشه‌ی وب روی ریشه‌ی پروژه و لو رفتن .env.
