ساخت پورتفولیو و GitHub

کارفرما و مصاحبه‌گر اول کارهای تو را می‌بینند، نه رزومه را.

۱. چه چیزی نشان بدهیم

۳ تا ۵ پروژه‌ی کامل (مثل فروشگاه، خبری و رزرو دوره) با نسخه‌ی آنلاین، README خوب و تصویر صفحه. کیفیت مهم‌تر از تعداد است.

۲. Git و GitHub

کدgit
git init
git add .
git commit -m "feat: first version"
git branch -M main
git remote add origin https://github.com/USER/REPO.git
git push -u origin main

۳. README

نام و هدف پروژه، تصویر، فناوری‌ها، دستور نصب (مثل همین دوره)، حساب آزمایشی و لینک نمایش زنده. هرگز .env را Push نکن؛ در .gitignore هست.

اشتباه‌های رایج

  1. Push کردن .env و لو رفتن رمزها.
  2. پروژه‌های نیمه‌کاره و بی‌README در صفحه‌ی اصلی پروفایل.
