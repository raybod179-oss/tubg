ایمیل و پیامک

در توسعه، ایمیل را در لاگ ببین تا ایمیل واقعی نرود؛ در پروداکشن SMTP واقعی بگذار. پیامک از طریق API سرویس‌دهنده‌ی داخلی ارسال می‌شود.

۱. تنظیم ایمیل

با log متن ایمیل در storage/logs/laravel.log می‌آید.

کدenv
# .env توسعه
MAIL_MAILER=log

# .env پروداکشن (نمونه)
MAIL_MAILER=smtp
MAIL_HOST=smtp.example.com
MAIL_PORT=587
MAIL_USERNAME=...
MAIL_PASSWORD=...
MAIL_FROM_ADDRESS=info@yoursite.ir

۲. ساخت و ارسال

کدMail
php artisan make:mail WelcomeMail --markdown=emails.welcome

use Illuminate\Support\Facades\Mail;
Mail::to($user->email)->send(new WelcomeMail($user));
// صف: ->queue(new WelcomeMail($user))

۳. پیامک

هر سرویس‌دهنده (مثل کاوه‌نگار، ملی‌پیامک و ...) مستندات و آدرس API خودش را دارد. الگوی کلی با Http:

کدSMS
use Illuminate\Support\Facades\Http;

Http::post(config('services.sms.url'), [
    'apikey'   => config('services.sms.key'),
    'receptor' => $mobile,
    'message'  => 'کد تأیید شما: 12345',
]);
// آدرس و نام فیلدها را از مستندات سرویس‌دهنده‌ی خودت بگیر

۴. تمرین

ایمیل خوش‌آمدگویی بعد از ثبت‌نام بفرست و آن را به صف ببر.

اشتباه‌های رایج

  1. گذاشتن رمز SMTP در کد به‌جای .env.
  2. تست روی ایمیل واقعی مشتری؛ در توسعه از log استفاده کن.
