ساخت API و Resource

API یعنی سایت به‌جای صفحه‌ی HTML، داده‌ی JSON بدهد تا اپ موبایل یا فرانت‌اند جدا از آن استفاده کند.

۱. فعال‌کردن API

لاراول ۱۲ و ۱۳ به‌طور پیش‌فرض فایل routes/api.php ندارد؛ این دستور آن را می‌سازد و Sanctum را هم نصب می‌کند.

کدartisan
php artisan install:api

۲. Resource

Resource شکل خروجی JSON را کنترل می‌کند تا ستون‌های داخلی دیتابیس لو نروند.

کدResource
php artisan make:resource ProductResource

// app/Http/Resources/ProductResource.php
public function toArray(Request $request): array
{
    return [
        'id'    => $this->id,
        'name'  => $this->name,
        'price' => $this->price,
        'category' => $this->whenLoaded('category', fn () => $this->category->name),
    ];
}

۳. روت و کنترلر

مسیرهای این فایل خودکار پیشوند /api می‌گیرند.

کدroutes/api.php
// routes/api.php
use App\Http\Resources\ProductResource;
use App\Models\Product;

Route::get('/products', fn () =>
    ProductResource::collection(Product::with('category')->paginate(12))
);

Route::get('/products/{product}', fn (Product $product) =>
    new ProductResource($product)
);

۴. تست با مرورگر یا Postman

آدرس http://127.0.0.1:8000/api/products را باز کن؛ JSON می‌بینی. برای درخواست‌های POST از Postman یا Insomnia استفاده کن و هدر Accept: application/json را حتماً بگذار.

اشتباه‌های رایج

  1. نفرستادن هدر Accept: application/json و گرفتن ریدایرکت HTML به‌جای خطای JSON.
  2. برگرداندن مدل خام و لورفتن ستون‌هایی مثل password.
