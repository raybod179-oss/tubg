Docker و محیط توسعه

Docker محیط یکسان (PHP، MySQL و ...) را برای همه‌ی اعضای تیم می‌سازد. لاراول ابزار رسمی آن، Sail، را دارد.

۱. پیش‌نیاز

Docker Desktop. در ویندوز باید WSL2 فعال باشد و دستورها داخل ترمینال WSL اجرا شوند.

۲. پروژه‌ی جدید و موجود

کدsail
# پروژه‌ی تازه (لینوکس/WSL)
curl -s "https://laravel.build/my-app" | bash

# پروژه‌ی موجود
composer require laravel/sail --dev
php artisan sail:install

۳. کار با Sail

کدsail
./vendor/bin/sail up -d
./vendor/bin/sail artisan migrate --seed
./vendor/bin/sail composer install
./vendor/bin/sail down

اشتباه‌های رایج

  1. اجرای Sail در PowerShell ویندوز به‌جای WSL.
  2. اشغال‌بودن پورت 80 یا 3306 توسط XAMPP؛ XAMPP را خاموش کن یا پورت را عوض کن.
