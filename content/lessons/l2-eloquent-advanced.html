Eloquent پیشرفته: Scope، Accessor و Eager Loading

بعد از CRUD و روابط، سه ابزار کدت را کوتاه‌تر و سریع‌تر می‌کند: Scope برای کوئری‌های تکراری، Accessor برای فرمت داده و Eager Loading برای حذف مشکل N+1.

۱. Local Scope

شرطی که بارها می‌نویسی را یک‌بار در مدل تعریف کن:

کدScope (لاراول ۱۲ و ۱۳)
// app/Models/Product.php
use Illuminate\Database\Eloquent\Attributes\Scope;
use Illuminate\Database\Eloquent\Builder;

#[Scope]
protected function active(Builder $query): void
{
    $query->where('is_active', true);
}

// استفاده
Product::active()->latest()->paginate(12);

۲. Accessor

ویژگی محاسبه‌شده بساز، مثل قیمت فرمت‌شده:

کدAccessor
use Illuminate\Database\Eloquent\Casts\Attribute;

protected function priceFormatted(): Attribute
{
    return Attribute::get(fn () => number_format($this->price) . ' تومان');
}

// {{ $product->price_formatted }}

۳. مشکل N+1 و Eager Loading

اگر برای هر محصول جدا دسته‌اش را بخوانی، ۱۰۰ محصول یعنی ۱۰۱ کوئری. با with فقط ۲ کوئری:

کدwith()
// بد: N+1
$products = Product::all();
foreach ($products as $p) { echo $p->category->name; }

// خوب
$products = Product::with('category')->get();

۴. شمارش و جمع روی رابطه

بدون لود کردن همه‌ی ردیف‌ها:

کدwithCount
$categories = Category::withCount('products')->get();
// $category->products_count

۵. تمرین

scope به نام cheaperThan($price) بنویس و با Debugbar یا DB::listen تعداد کوئری‌های صفحه‌ی محصولات را قبل و بعد از with مقایسه کن.

اشتباه‌های رایج

  1. فراموش‌کردن with در حلقه‌ها و ایجاد N+1.
  2. استفاده از Accessor برای کارهای سنگین (هر بار اجرا می‌شود).
  3. قراردادن منطق کوئری در ویو به‌جای Scope.
