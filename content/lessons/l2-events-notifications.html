Event، Listener و Notification

Event یعنی «اتفاقی افتاد» (سفارش ثبت شد) و Listener یعنی «واکنش به آن». Notification پیام به کاربر است.

۱. ساخت

لاراول Listenerها را از روی نوع Event در متد handle خودکار پیدا می‌کند.

کدartisan
php artisan make:event OrderPlaced
php artisan make:listener SendOrderNotification --event=OrderPlaced

۲. استفاده

کدEvent/Listener
// Event
class OrderPlaced { public function __construct(public Order $order) {} }

// Listener
public function handle(OrderPlaced $event): void
{
    $event->order->user->notify(new OrderPlacedNotification($event->order));
}

// بعد از ثبت سفارش
OrderPlaced::dispatch($order);

۳. Notification

هر Notification چند کانال دارد: ایمیل، دیتابیس (زنگوله‌ی سایت) و ...

کدNotification
php artisan make:notification OrderPlacedNotification

public function via(object $notifiable): array
{
    return ['mail', 'database'];
}

public function toMail(object $notifiable): MailMessage
{
    return (new MailMessage)->subject('سفارش شما ثبت شد')->line('ممنون از خرید شما');
}

۴. تمرین

وقتی مدیر وضعیت سفارش را «ارسال‌شده» کرد، رویداد و اعلان بساز.

اشتباه‌های رایج

  1. انجام همه‌چیز داخل کنترلر به‌جای Event؛ کنترلر بزرگ و تست‌ناپذیر می‌شود.
  2. فراموش‌کردن ShouldQueue برای Listenerهای کند.
