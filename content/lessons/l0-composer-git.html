Composer و Git در عمل

Composer پکیج‌های PHP را مدیریت می‌کند و Git تاریخچه‌ی کد را نگه می‌دارد؛ هر دو در هر پروژه‌ی لاراولی لازمند.

۱. Composer

کدcomposer
composer require spatie/laravel-permission   # نصب پکیج
composer install                           # نصب از composer.lock
composer update                            # به‌روزرسانی
composer dump-autoload                     # رفع Class not found

۲. Git روزمره

کدgit
git status
git add .
git commit -m "توضیح تغییر"
git log --oneline
git switch -c feature/cart   # شاخه‌ی جدید

۳. gitignore

پوشه‌ی vendor و فایل .env هرگز Commit نمی‌شوند؛ پروژه‌ی تازه‌ی لاراول از قبل آن‌ها را در .gitignore دارد.

اشتباه‌های رایج

  1. Commit کردن vendor یا .env.
  2. ویرایش دستی composer.lock.
