مبانی PHP ۳: شی‌گرایی (OOP)

لاراول کاملاً شی‌گراست: مدل، کنترلر و سرویس همه کلاس‌اند. این درس همان قدر OOP می‌گوید که برای لاراول لازم داری.

۱. کلاس و شیء

کلاس نقشه است، شیء ساخته‌ی آن. $this یعنی همین شیء.

کدکلاس
<?php
class Product
{
    public function __construct(
        public string $name,
        public int $price,
    ) {}

    public function label(): string
    {
        return "{$this->name} - {$this->price}";
    }
}

$p = new Product('هدفون', 450000);
echo $p->label();

۲. سطح دسترسی

public از همه‌جا، protected از خود کلاس و فرزندان، private فقط از خود کلاس. اطلاعات حساس را private کن.

۳. وراثت

فرزند همه‌ی ویژگی‌های والد را می‌گیرد؛ در لاراول هر مدل از Model ارث می‌برد.

کدextends
<?php
class DigitalProduct extends Product
{
    public function label(): string
    {
        return parent::label() . ' (دانلودی)';
    }
}

۴. اینترفیس و namespace

اینترفیس قرارداد است؛ namespace از تداخل نام‌ها جلوگیری می‌کند (همان App\Models).

کدinterface
<?php
namespace App\Services;

interface Payable
{
    public function pay(int $amount): bool;
}

class ZarinpalGateway implements Payable
{
    public function pay(int $amount): bool { return true; }
}

۵. تمرین

کلاس Cart با متدهای add، total و count بنویس که آرایه‌ای از شیءهای Product را نگه دارد.

اشتباه‌های رایج

  1. نوشتن $name به‌جای $this->name داخل کلاس.
  2. فراموش‌کردن new هنگام ساخت شیء.
  3. نام‌گذاری فایل کلاس با اسمی غیر از نام کلاس.
