شروع دوره

مقدمه، هدف و مرور کلی دوره

سلام و درود رفقای Rayvo این دوره‌ی متنی و پروژه‌محور است: بدون ویدیو، با توضیح و کدی که اجرا می‌کنی. هدف این است که کسی که هیچ‌چیز از برنامه‌نویسی و لاراول نمی‌داند، قدم‌به‌قدم به یک لاراول‌دولوپر تبدیل شود.

چرا متنی؟

چون می‌توانی مستقیم سراغ درس موردنیازت بروی، سریع مرور کنی و وقتت را صرف کدنویسی و تمرین کنی، نه فقط تماشا. کدها را کورکورانه کپی نکن؛ هدف فهمیدن این است که هر بخش چطور کار می‌کند.

مسیر دوره

سطح ۰: ابزارها، PHP و SQL ← سطح ۱: مقدماتی لاراول ← پروژه‌ی فروشگاه (با سورس zip) ← سطح ۲: متوسط ← پروژه‌ی سایت خبری ← پروژه‌ی رزرو وقت ← سطح ۳: پیشرفته ← مارکت‌پلیس چندفروشنده ← سطح ۴: کار و درآمد. هر درس حدود ۴۰ تا ۹۰ دقیقه است؛ با روزی یک تا دو درس، مسیر در حدود دو ماه طی می‌شود.

نصب هر پروژه‌ی zip (الگوی کلی)

همه‌ی پروژه‌های دوره یک «لایه‌ی روی لاراول» هستند. الگوی نصب همیشه یکی است (نام پوشه را عوض کن):

کدنصب پروژه
composer create-project laravel/laravel my-project
cd my-project

# ویندوز (PowerShell):
tar -xf "$env:USERPROFILE\Downloads\project-source.zip" -C .
# مک / لینوکس:
unzip -o ~/Downloads/project-source.zip -d .

composer install
cp .env.example .env        # ویندوز: copy .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
php artisan serve

فرمان‌های روزمره

این‌ها را بارها استفاده می‌کنی:

کددستورات
php artisan serve                 # اجرای سایت روی 127.0.0.1:8000
php artisan migrate:fresh --seed  # ساخت دوباره‌ی دیتابیس (داده‌ها پاک می‌شود)
php artisan make:model Post -mfc  # مدل + migration + factory + controller
php artisan route:list            # فهرست روت‌ها
php artisan optimize:clear        # پاک‌کردن کش‌ها
php artisan test                  # اجرای تست‌ها
composer dump-autoload            # رفع خطای Class not found

پشتیبانی

سؤال داری؟ از کانال‌های Rayvo (تلگرام، بله، یوتیوب و آپارات) پیام بده؛ لینک‌ها پایین هر صفحه است.

اشتباه‌های رایج

  1. رفتن سراغ پروژه قبل از درس‌های پایه؛ اول سطح ۰ و ۱ را بخوان.
  2. کپی‌کردن کد بدون اجرا؛ هر کد را خودت بزن و تغییرش بده.
  3. استخراج zip بیرون از پوشه‌ی پروژه.
