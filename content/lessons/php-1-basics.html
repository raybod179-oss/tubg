مبانی PHP ۱: متغیر، شرط و حلقه

قبل از لاراول باید زبانش را بفهمی. در این درس PHP را از صفر می‌نویسی و اجرا می‌کنی؛ هیچ پیش‌زمینه‌ای لازم نیست.

۱. اولین فایل PHP

XAMPP را روشن کن (Apache = Start). پوشه‌ی C:\xampp\htdocs\php-lab را بساز و داخلش فایل index.php را با VS Code بنویس. بعد در مرورگر برو به http://localhost/php-lab/. اگر Laragon داری، پوشه را در C:\laragon\www بساز.

کدphp-lab/index.php
<?php
echo 'سلام Rayvo!';

۲. متغیر و انواع داده

متغیر در PHP با $ شروع می‌شود. چهار نوع پایه: رشته، عدد صحیح، اعشاری و بولی.

کدمتغیرها
<?php
$name  = 'علی';
$age   = 25;
$price = 199.5;
$isPaid = true;

echo "سلام $name، سن تو $age است";
var_dump($price); // float(199.5)

۳. شرط

با if / elseif / else تصمیم می‌گیری. مقایسه‌ی دقیق را همیشه با === بنویس.

کدif / else
<?php
$stock = 0;
if ($stock > 5) {
    echo 'موجود';
} elseif ($stock > 0) {
    echo 'تعداد کم';
} else {
    echo 'ناموجود';
}

۴. حلقه

for وقتی تعداد تکرار معلوم است و foreach برای آرایه‌ها (در درس بعد عمیق‌تر).

کدحلقه‌ها
<?php
for ($i = 1; $i <= 5; $i++) {
    echo "محصول $i<br>";
}

$items = ['قلم', 'دفتر', 'مداد'];
foreach ($items as $item) {
    echo $item . '<br>';
}

۵. تمرین

برنامه‌ای بنویس که اعداد ۱ تا ۲۰ را چاپ کند؛ مضرب ۳ را «سه» و مضرب ۵ را «پنج» نشان بدهد (راهنما: عملگر %).

اشتباه‌های رایج

  1. فراموش‌کردن ; در انتهای دستور.
  2. نوشتن = به‌جای == در شرط.
  3. باز کردن فایل با دابل‌کلیک به‌جای آدرس localhost (PHP اجرا نمی‌شود).
