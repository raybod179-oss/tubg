مبانی PHP ۲: آرایه و تابع

آرایه‌ها و تابع‌ها پایه‌ی هر کد لاراولی‌اند؛ کالکشن‌ها، کانفیگ‌ها و نتیجه‌ی دیتابیس همه آرایه‌اند.

۱. آرایه‌ی ساده و انجمنی

آرایه‌ی ساده با اندیس عددی و آرایه‌ی انجمنی با کلید متنی (مثل ردیف یک جدول):

کدآرایه
<?php
$colors = ['قرمز', 'آبی'];
$colors[] = 'سبز';          // افزودن
echo count($colors);        // 3

$product = ['name' => 'هدفون', 'price' => 450000];
echo $product['name'];

۲. حلقه روی آرایه

foreach با کلید و مقدار:

کدforeach
<?php
foreach ($product as $key => $value) {
    echo "$key: $value<br>";
}

$prices = [100, 250, 80];
echo array_sum($prices);          // 430
sort($prices);                    // مرتب‌سازی

۳. تابع

تابع کار تکراری را یک‌جا می‌نویسد. نوع ورودی و خروجی را بنویس تا خطا زود پیدا شود.

کدfunction
<?php
function finalPrice(int $price, int $discount = 0): int
{
    return $price - ($price * $discount / 100);
}

echo finalPrice(200000, 10); // 180000

۴. تابع بی‌نام و array_map

در لاراول زیاد می‌بینی: تابع کوتاه fn.

کدfn
<?php
$names = ['علی', 'سارا'];
$upper = array_map(fn ($n) => "کاربر: $n", $names);
$cheap = array_filter([50, 500, 90], fn ($p) => $p < 100);

۵. تمرین

تابعی بنویس که آرایه‌ای از قیمت‌ها را بگیرد و میانگین آن را برگرداند؛ سپس فقط قیمت‌های بالاتر از میانگین را با array_filter بیرون بکش.

اشتباه‌های رایج

  1. استفاده از $arr[name] بدون کوتیشن.
  2. فراموش‌کردن return در تابع.
  3. تغییر آرایه‌ی اصلی با sort بدون توجه به اینکه آرایه را عوض می‌کند.
