احراز هویت API با Sanctum

اپ موبایل کوکی و سشن ندارد؛ با توکن وارد می‌شود. Sanctum ساده‌ترین راه توکن‌دادن در لاراول است.

۱. آماده‌سازی

اگر install:api را زده‌ای Sanctum نصب است. مدل User باید trait داشته باشد:

کدUser.php
use Laravel\Sanctum\HasApiTokens;

class User extends Authenticatable
{
    use HasApiTokens, Notifiable;
}

۲. ورود و ساخت توکن

کدlogin
// routes/api.php
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

Route::post('/login', function (Request $request) {
    $data = $request->validate(['email' => 'required|email', 'password' => 'required']);

    if (! Auth::attempt($data)) {
        return response()->json(['message' => 'ایمیل یا گذرواژه اشتباه است'], 422);
    }

    $token = $request->user()->createToken('mobile')->plainTextToken;
    return ['token' => $token];
});

۳. محافظت از روت

کلاینت توکن را در هدر Authorization: Bearer TOKEN می‌فرستد.

کدauth:sanctum
Route::middleware('auth:sanctum')->group(function () {
    Route::get('/me', fn (Request $r) => $r->user());
    Route::post('/logout', function (Request $r) {
        $r->user()->currentAccessToken()->delete();
        return response()->noContent();
    });
});

۴. تمرین

API سفارش‌های کاربر وارد‌شده را بنویس (فقط سفارش‌های خودش) و با Postman تست کن.

اشتباه‌های رایج

  1. ذخیره‌ی توکن در جای ناامن؛ توکن مثل گذرواژه است.
  2. فراموش‌کردن حذف توکن هنگام خروج.
